# Arcade hackathon integration prototype

Build a local wrapper for an actual public Arcade game. The user needs to operate Six Seven Arena with a joystick and mapped action buttons outside an embedded player, and view a separate camera at the player’s head next to the controls. Completion requires real game movement, game actions, and a live camera feed working together. This experiment supports later Quest integration but does not yet provide immersive VR.

The installed Chrome extension runs in Arcade’s page world. The local server binds only to loopback. Preserve Arcade’s normal gameplay and original view. Prefer clear status, easy release/stop, and direct controls over decorative presentation. Users are hackathon developers operating a desktop browser. The established lab uses neutral light surfaces and dark game/diagnostic areas; the controller continues that visual language with restrained green interaction controls.
